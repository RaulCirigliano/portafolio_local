# Metodología de Proyectos (Directiva de IA)

Esta regla aplica para este portafolio y sus subproyectos. Como asistente de IA, debes seguir SIEMPRE la siguiente metodología:

1. **Contexto Inicial**: Al empezar cualquier tarea, revisa siempre si existe un archivo `contexto.md`, `README.md` o similar para entender de qué trata y el estado actual.
2. **Actualización Constante**: Cada vez que modifiques código o comportamiento, actualiza dicho documento de contexto.
3. **Control de Versiones Automático**: Al finalizar cambios, realiza un `git commit` y `git push` automáticamente.
4. **Mantenimiento del Portafolio**: 
   - Mantén actualizado el índice y los enlaces de los proyectos aquí en el portafolio.
